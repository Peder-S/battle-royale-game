# Battle Royale Game

Fast-paced top-down multiplayer battle royale built with Node.js, Express, Socket.IO, and an HTML5 canvas frontend.

## Features

- Real-time multiplayer combat in the browser
- Shrinking storm zone that forces fights inward
- Randomized obstacle layouts each round
- Loot pickups for fire rate, range, and damage
- Forward dash movement on `Shift`
- Adaptive bots based on human player count

## Controls

- `WASD`: Move
- `Mouse`: Aim
- `Left Click`: Shoot
- `Shift`: Forward dash

## Run Locally

```bash
npm install
npm start
```

Then open [http://localhost:3001](http://localhost:3001).

## Tech

- Node.js
- Express
- Socket.IO
- HTML5 Canvas
